# Streamflix — a Netflix-style UI clone (demo)

A single-file, front-end **UI clone** of a streaming service browse page, built for
learning and portfolio purposes.

> **Not affiliated with Netflix.** This is a static mock-up. There are no real videos,
> no accounts, and it does not collect any login or payment information. All titles,
> artwork and details shown are fictional.

## What it is
- Dark, cinematic browse UI: fixed nav, hero banner, horizontally scrolling rows,
  hover-scaling cards, a Top 10 row, and a title detail modal.
- Everything (HTML + CSS + JS) lives in one self-contained `index.html` — no build step,
  no dependencies except Google Fonts.

## Run it
Just open `index.html` in a browser, or visit the GitHub Pages link.
